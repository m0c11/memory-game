# Освещение и материалы актового зала

Рендерер проекта — **Compatibility в Godot 4.6**. Свет и материалы настроены в ресурсах и сценах, доступны в редакторе до запуска игры.

## Материалы

- `materials/blue_upholstery.tres` — единый материал сиденья, передней и задней стороны спинки. Использует цвет, нормали и шероховатость из исходного набора; слабый эффект Rim имитирует рассеивание света на ворсе ткани.
- `materials/stage_maple.tres` — деревянный настил с повторением текстуры досок, рельефом волокон, картой шероховатости и тонким слоем лака Clearcoat.
- `materials/hall_environment.tres` — небольшая холодная фоновая подсветка, тональная компрессия, деликатные контраст/насыщенность и свечение ярких ламп.

Карты `*_orm.png` используют зелёный канал для шероховатости. Исходные GLB не изменены: новые материалы назначены поверх отдельных мешей в сценах кресла и сцены.

## Свет

В `scenes/levels/auditorium.tscn`:

- `Lighting/StageWarmLeft`, `StageWarmRight`, `StageSoftFill` освещают сцену тёплым светом.
- `AudienceFillLeft`, `AudienceFillRight`, `FrontFillLeft`, `FrontFillRight`, `RearFill` распределяют мягкий свет по залу.
- `RoomReflections` даёт локальные отражения помещения для лака и металлических деталей.
- `BakedLighting` — LightmapGI для статичного окружения. Размеры источников влияют на мягкость запечённых теней.
- У динамической капсулы включён Dynamic GI: она может получать свет из проб LightmapGI, сохраняя освещение при движении.

Тени статичных объектов сохранены в световых картах. Для потолочных OmniLight и ReflectionProbe расчёт теней во время игры отключён, чтобы снизить нагрузку. Два сценических SpotLight сохраняют динамические тени; движущаяся капсула не отбрасывает тень от каждого потолочного источника.

Текстуры импортируются с компрессией для видеопамяти и mip-уровнями; карты нормалей отмечены как Normal Map. Эти параметры сохранены в `.import`.

## Повторное запекание

При изменении геометрии или источников света обновите запекание:

1. Откройте `scenes/levels/auditorium.tscn` в редакторе Godot.
2. Дождитесь окончания импорта GLB. Для статичных моделей в Import установлен `Meshes → Light Baking → Static Lightmaps`.
3. Выделите `BakedLighting` и нажмите **Bake Lightmaps** над 3D-видом.
4. Сохраняйте результат в `res://assets/lighting/auditorium.lmbake`; сохраните сцену после запекания.
5. Проверьте общий вид и первое лицо, затем добавьте изменённые `.lmbake`, изображения световых карт, их `.import` и сцену в коммит.

Для запекания нужен компьютер с поддержкой RenderingDevice/Vulkan. Готовые карты освещения используются при запуске в Compatibility; игроку не требуется запекать их заново. Временные `.unwrap_cache` и `.godot/` исключены из Git.

Бутылка воды оставлена в режиме Static без собственной световой карты: её мелкие поверхности вызывают ошибку UV2-развёртки xatlas. Она получает обычное освещение. Её исходная геометрия сохранена.

## Проверенный результат

Световые карты запечены и включены в репозиторий. После запекания проверены чистый импорт проекта без `.godot`, запуск главной сцены и оба ракурса в Compatibility на Godot 4.6.3. Снимки `level01.png` и `level01-detail.png` получены из работающей сцены; `level01-before-lighting.png` сохраняет предыдущий вид. Проверка выполнялась с программным рендерером llvmpipe, поэтому производительность на компьютере игрока нужно оценивать отдельно.
