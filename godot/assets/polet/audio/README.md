# Last evening

`last_evening.wav` — оригинальный короткий инструментальный эскиз для этого проекта: 16 секунд, mono PCM, 22050 Hz. Создан офлайн синтезом простых тонов, без заимствованной записи. Рабочая музыка для проверки звука и последнего вечера; впоследствии можно заменить пользовательской композицией. Повтор управляется готовым AudioStreamPlayer в сцене Story. При запуске игры аудио не генерируется.
