# Звук «Полёта»

Все WAV в этой папке — оригинальные офлайн-синтезированные записи, без сторонних семплов: ветер и птицы (`camp_air`, 24 с), тихая инструментальная тема (`last_evening`, 32 с), шаг, ткань, бумага, уборка, дверь, щелчок, подтверждение, рация, колокольчик, кочка и музыкальный сигнал. Mono PCM, 22050 Hz. Источник — `art/polet_cast/author_audio.py`.

Аудио загружается обычными AudioStreamPlayer из сцен `presentation.tscn`, `player.tscn`, `story.tscn`; синтеза при запуске нет. Реплики отображаются текстом, голосовая озвучка не входит в эту версию.
