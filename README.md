# Год 19 → 20

Новая версия игры разрабатывается в папке **[godot](godot/)**. Откройте `godot/project.godot` в Godot 4.6 и нажмите **F5**. [Инструкция и скриншот первого уровня](godot/README.md).

Ниже — описание прежнего 2D-прототипа на libGDX (Java).

## Что уже есть

- Главное меню
- Персонаж с плавным движением (ускорение/трение) и коллизиями
- Три игровые комнаты + финальная
- Интерактивные объекты с диалогами (клавиша `E`)
- Гейтинг: дверь открывается только когда все объекты в комнате использованы
- Система тонирования сцены — от серого к цветному (по мере истории)
- Диалоги и комнаты в духе Undertale: чёрная плашка с белой обводкой, текст
  печатается по буквам со «* », портрет говорящего, прожектор вокруг героини и
  пиксельная рамка-виньетка
- Точки сохранения — тёплая звёздочка: подойди и нажми `Z`
- Глава 1: «тревожная шкала» — она заполняется, пока героиня ходит; когда
  полна, надо успеть нажать `Пробел`, иначе спотыкаешься
- БОСС 1 «Танец» — ритм-игра в духе Piano Tiles: по 4 дорожкам съезжают
  стрелки, их нужно нажимать в такт музыке (`assets/music/boos_1_level.mp3`)
- Экран финала
- Кириллица через системный .ttf
- Никаких ассетов скачивать не нужно — текстуры генерируются кодом

## Требования

- JDK 17+ (`java --version`)
- Gradle 8.x (`gradle --version`)
    - если Gradle нет: `sudo apt install gradle`
    - или через SDKMAN: `sdk install gradle 8.5`

## Как запустить

Первый запуск:
```bash
gradle wrapper --gradle-version 8.5   # создаст ./gradlew (один раз)
./gradlew desktop:run
```

Или сразу:
```bash
gradle desktop:run
```

## Как собрать .jar

```bash
./gradlew desktop:jar
# готовый файл появится в ./dist/
java -jar dist/desktop-0.1.0.jar
```

## Управление

- `WASD` / стрелки — движение
- `Z` — взаимодействовать с объектом / сохраниться у звёздочки / продолжить диалог
- `E` / `Enter` / `Пробел` — тоже подтверждение в диалогах (как в Undertale)
- `Пробел` — «выдохнуть» (сбросить тревожную шкалу в главе 1)
- В боссе: `← ↓ ↑ →` (или `W A S D`) — попадать по стрелкам в такт
- `ESC` — выйти в меню / пропустить босса

## Боссы (ритм)

Партия нот генерируется в `RhythmChart.java` под темп музыки. Для
`boos_1_level.mp3` темп измерен как **BPM 114**, первая сильная доля —
на **12.6 с**. Если заменишь трек, поправь `BPM`, `START` и `LENGTH`
в `core/src/com/mygame/mechanics/RhythmChart.java`.

## Куда смотреть дальше

- Хочешь новую комнату — добавь кейс в `RoomFactory.java` и увеличивай `ROOM_COUNT`.
- Хочешь новую механику — оберни её в отдельный класс-«систему» и вызывай из `GameScreen.update()`.
- Хочешь настоящие спрайты — замени `createTexture(...)` в `Assets.java` на `new Texture("...png")`.
